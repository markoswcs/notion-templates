# Notion Templates

> Landing page para venda de templates premium do Notion.

Este repositório contém a página estática de vendas e o portfólio de templates focados em produtividade no Notion.

## 📂 Estrutura do Projeto
- `index.html`: A página principal de vendas.
- `CRIATIVOS/`: Imagens, vídeos e assets visuais utilizados na página e em anúncios.

## ☁️ Rodando pelo GitHub (Codespaces)
O projeto está configurado para abrir diretamente no GitHub Codespaces! 
1. Clique no botão **Code** > **Codespaces** > **Create codespace**.
2. O ambiente vai iniciar o Live Server e abrirá uma aba no navegador exibindo a página.
