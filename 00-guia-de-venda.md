## 🛠️ COMO MONTAR (Passo a Passo)

### Passo 1: Abra o Notion
- Crie uma conta gratuita em notion.so (se não tiver)
- Crie uma página nova para cada template

### Passo 2: Siga o Blueprint
- Abra o arquivo `.md` do template
- Crie cada database com as propriedades listadas
- Configure as views conforme descrito
- Monte o layout da página principal
- Preencha os dados de exemplo

### Passo 3: Publique o Template
1. Clique em **"Share"** (canto superior direito)
2. Clique em **"Publish"**
3. Ative **"Allow duplicate as template"**
4. Copie o link gerado — este é o link de entrega

### Passo 4: Configure na Plataforma de Vendas

**Opção A — Kiwify (recomendado pra BR)**
1. Crie conta em kiwify.com.br
2. Crie produto digital
3. Preço: R$9,90 / R$14,90 / R$29,90 (pack)
4. Entrega: Coloque o link do Notion na entrega automática
5. Checkout integrado com PIX

**Opção B — Hotmart**
1. Crie conta em hotmart.com
2. Mesmo processo, mas com mais opções de afiliados

**Opção C — Gumroad (se quiser vender lá fora também)**
1. Crie conta em gumroad.com
2. Permite venda em USD e BRL
